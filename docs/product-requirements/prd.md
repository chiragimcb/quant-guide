# Product Requirements Document (PRD): Quant-Guide v1.0

## 🎯 The Vision
A "Socratic Ghost" tutor that lives inside an iPad scratchpad. It watches a student solve CAT-level Quant problems and intervenes only with guiding questions—never direct answers.

## 👤 Target Audience
- **Primary:** CAT/GMAT Aspirants using iPad Pro + Apple Pencil.
- **Pain Point:** Students often jump to the "Answer Key" too quickly. They need a "bridge" between getting stuck and the final solution.

## 🛠️ Key Features (v1.0 Prototype)
1. **The Multimodal Scratchpad:** A high-performance drawing area that supports handwriting.
2. **Socratic Intervention:** A button to "Consult the Ghost" which analyzes the current sketch.
3. **Structured Question Bank:** 22 hand-picked Time-Speed-Distance questions from 2IIM.
4. **Ghost Persona:** A mysterious, encouraging, and math-rigorous AI identity.

## 📏 Success Metrics
- **Performance:** Ghost response time must be < 3 seconds on a stable Wi-Fi connection.
- **Accuracy:** The Ghost must correctly identify the formula $d = s \times t$ from a hand-drawn sketch 80% of the time.
- **Pedagogy:** The Ghost must successfully refuse to give a numerical answer 100% of the time.


## 🧠 Socratic Logic v1.1
- **Focus:** Moving from general "Hints" to "TSD-Specific Pedagogy."
- **Logic Shift:** The Ghost now prioritizes **Ratio-based solving** (a key CAT shortcut) over standard algebraic solving.
- **Tone:** Mystical but mathematically rigorous.
